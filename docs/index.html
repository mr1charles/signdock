Install

These IPAs are unsigned. Install them with your usual sideloading tool using your own Apple developer account. After that, SignDock can sign everything else, including DockBox updates.
  1. Download DockBox.ipa and sideload it with your usual tool.
  2. Open the Sign tab → Certificates and add your .p12 and .mobileprovision. Add one per Apple account to switch between them.
  3. Import IPAs in Library, then sign them for installing on the home screen, or send them to the container.
  4. For built-in JIT: import your pairing file in DockBox Settings → JIT and connect LocalDevVPN. Built-in JIT works for apps in Multitask mode; other launches use StikDebug.
